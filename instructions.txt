**Objective:** Modify the `ReservoirLayer` and `ReservoirLM` classes to incorporate three new optional features: a GRU-style gating mechanism, learnable head projections, and a hybrid attention/reservoir mode.

#### **Feature 1: Implement Gating Mechanism**

1.  **Modify `ReservoirLayer.__init__`:**

      * Add a new boolean argument `use_gating=False`.
      * Inside the `__init__` method, add the following conditional block to create the gating layer:
        ```python
        self.use_gating = use_gating
        if self.use_gating:
            self.gate_proj = nn.Linear(d_model, d_model)
        ```

2.  **Modify `ReservoirLayer.forward`:**

      * Locate the first residual connection line: `x = self.norm1(x + x_res)`.
      * Replace it with the following conditional logic:
        ```python
        if self.use_gating:
            g = torch.sigmoid(self.gate_proj(x))
            x = self.norm1(x * (1 - g) + x_res * g)
        else:
            x = self.norm1(x + x_res)
        ```

#### **Feature 2: Implement Learnable Head Projections**

1.  **Modify `ReservoirLayer.__init__`:**

        if self.use_head_projs:

#### **Feature 3: Implement Hybrid Attention/Reservoir Layer**
